# DC-Motor-Control-Using-L293D
‏## Overview

‏This project demonstrates how to control four DC motors using an Arduino Uno and two L293D motor driver ICs in Tinkercad. The motors follow a predefined movement sequence by changing their rotation direction according to the program.

‏## Features

‏- Control four DC motors using two L293D motor drivers.
‏- Forward movement for 30 seconds.
‏- Backward movement for 60 seconds.
‏- Alternate right and left turns for 60 seconds.
‏- Simulated using Tinkercad.
‏- Programmed using Arduino IDE (C/C++).

‏## Components

‏- Arduino Uno R3
‏- 2 × L293D Motor Driver IC
‏- 4 × DC Motors
‏- Breadboard
‏- Jumper Wires
‏- Power Supply

‏## Software

‏- Arduino IDE
‏- Tinkercad

‏## Project Structure

‏DC-Motor-Control-Using-L293D/
‏│── skitch.ino
‏│── README.md
##Movement Sequence

1. Move forward for 30 seconds.
2. Move backward for 60 seconds.
3. Alternate between right and left turns for 60 seconds.

1. Upload the `.ino` sketch file to the Arduino board in Tinkercad.
2. Click the **"Start Simulation"** button.
3. Observe the motors executing the forward, backward, and turning sequence automatically.
